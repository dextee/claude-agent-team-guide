These drawings were authored directly as SVG for this guide on 18 November 2026. The text and shapes are editable, with no external fonts, linked assets or image-generation service required. The icon is a 768 × 768 transparent PNG rendered from `team-mark.svg` in Chromium. To re-export, open the SVG at its intrinsic size and capture the `svg` element at device scale 1 with a transparent background.

The diagrams accompany text instructions and have descriptive alternatives where embedded. They explain control flow, not model performance. The [still-life artwork](../../assets/README.md) has its own provenance.
